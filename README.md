# Proyojon Mobile App

## Overview
Proyojon is a neighborhood marketplace mobile application designed to promote sustainable consumption and production, aligning with the United Nations Sustainable Development Goal (SDG) 12: Responsible Consumption and Production. Built using **React Native** with a **Firebase** backend, the app enables users to buy, sell, and donate items locally, fostering the "Reduce, Reuse, Recycle" initiative. It features a unique price bidding system inspired by eBay and a donation option to encourage community goodwill and environmental sustainability.

## Features
- **Buy and Sell Marketplace**: List and browse second-hand items within your neighborhood to reduce the demand for new products.
- **Price Bidding System**: Engage in competitive bidding for items, maximizing value for buyers and sellers.
- **Donation Option**: Donate items to local recipients or charities, promoting waste reduction and community support.
- **Local Focus**: Prioritize nearby transactions to minimize carbon footprints and strengthen community ties.
- **Chat**:  Messaging features to establish communication between users.
- **User Authentication**: Secure Firebase-based authentication for personalized profiles and safe transactions.
- **Geolocation**: Filter listings by proximity to encourage local exchanges.

## Motivation
The Proyojon app was created to address the growing need for sustainable waste management and resource reuse. By providing a platform for buying, selling, and donating items, it encourages users to extend product lifecycles and reduce environmental impact. The app's bidding and donation features add engagement and social responsibility, aligning with circular economy principles.

## Installation
To set up and run the Proyojon mobile app locally, follow these steps:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/ziftikhr/Proyojon_mobile-app.git
   cd Proyojon_mobile-app
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start the App**:
   ```bash
   npx expo start
   ```

4. **Run on a Device or Emulator**:
   - Use the Expo Go app on your iOS or Android device to scan the QR code generated by `npx expo start`.
   - Alternatively, run the app on an emulator using `npx expo start --android` or `npx expo start --ios`.

## Technologies Used
- **Frontend**: React Native (with Expo for development and testing)
- **Backend**: Firebase (authentication, real-time database, cloud storage)
- **Dependencies**: Managed via npm; see `package.json` for details.

## Project Structure
- `/components`: Reusable React Native components for the app's UI.
- `/screens`: Main screens for listing, browsing, bidding, and donating.
- `/firebase`: Configuration and utilities for Firebase integration.
- `/assets`: Images and static resources, including the app logo.

## Future Work
The Proyojon team plans to enhance the app with AI-driven features to further promote sustainability:
- **Recyclable Item Detection**: Use image recognition to identify recyclable items from user-uploaded photos.
- **Value Estimation**: Implement AI models to estimate item market value based on condition, age, and demand.
- **Recycler Connectivity**: Connect users with nearby recycling facilities for non-sellable items.

These enhancements aim to streamline decision-making for users and strengthen the app's alignment with SDG 12.
